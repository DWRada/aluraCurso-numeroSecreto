Este repositório foi criado para a finalidade de prosseguir com o curso Git & Github que está sendo feito na Alura.

Na primeira parte do curso aprendemos a criar a conta do github, criar o repositório, fazer a conexão do repositório local com o remoto e como sincronizá-los. Aprendemos como criar uma chave SSH para fazer a conexão com maior segurança. E aprendemos também a fazer a instalação do Git.

Na parte dois do curso, aprendemos como clonar um repositório, como realizar um commit com as boas práticas, e como compartilhar o projeto com outras pessoas colaboradoras, aprendemos sobre o comando git log, git add, git commit, git push, git pull e também git log.
